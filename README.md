# Service Center Demo

Адаптивный демонстрационный сайт для сервисного центра по ремонту техники.

[**Открыть сайт**](https://kimilyha.github.io/service-center-demo/)

## Возможности

- Каталог услуг
- Форма обращения
- Предпросмотр заявки для WhatsApp
- Адаптивная версия для мобильных устройств

## Технологии

HTML, CSS, JavaScript.
