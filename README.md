# ТехноПульс — демо-сайт сервисного центра

Статический адаптивный шаблон на HTML, CSS и JavaScript. Backend и платные зависимости не нужны. Название, номер, адрес и перечень услуг в проекте демонстрационные: сайт не представляет действующую компанию. `DEMO_MODE` включён по умолчанию, поэтому WhatsApp-кнопки открывают безопасный локальный предпросмотр и никогда не используют фиктивный номер.

## Локальный запуск

1. Распакуйте папку проекта или откройте её в редакторе.
2. Запустите любой локальный HTTP-сервер из этой папки, например:

   ```bash
   python -m http.server 8000
   ```

3. Откройте `http://localhost:8000`.

Можно открыть `index.html` напрямую, но локальный HTTP-сервер ближе к обычному размещению сайта.

## Адаптация под заказчика

В первую очередь измените `config.js`:

- `companyName` — название;
- `city` — город;
- `address` — реальный адрес или инструкция, если визит по адресу не предусмотрен;
- `whatsappNumber` — проверенный WhatsApp-номер, только цифры в международном формате;
- `services` — карточки услуг и подписи в форме;
- `hours` — резерв для расписания, сейчас не показывается.

Оставьте `DEMO_MODE: true` для показа шаблона. Для рабочего сайта установите `DEMO_MODE: false` и задайте проверенный `whatsappNumber`. Если режим выключен, а номер отсутствует или слишком короткий/длинный, кнопки покажут объяснение и не откроют внешнюю ссылку.

В `index.html` замените демонстрационные формулировки на подтверждённые условия заказчика. При необходимости добавьте его логотип и только предоставленные им фотографии и отзывы. В деморежиме реальный номер не показывается даже если он уже записан в конфигурации.

## Проверенные функции

- Карточки услуг и варианты формы строятся из `config.js`.
- Валидация требует выбрать услугу и описать проблему; имя необязательно.
- В деморежиме форма показывает локальное окно с текстом для WhatsApp; сообщения и данные никуда не передаются и не сохраняются.
- В рабочем режиме после выбора услуги и описания проблемы открывается `wa.me` с подготовленным сообщением. Отправка остаётся за пользователем.
- Верхние и нижние WhatsApp-кнопки в деморежиме показывают пояснение и пример текста; в рабочем режиме используют настроенный номер.
- Мобильное меню открывается и закрывается кнопкой и ссылками.
- Страница адаптируется под телефон, планшет и широкий экран; учитывает `prefers-reduced-motion`.

Внешний шрифт загружается с Google Fonts; если сеть недоступна, используются системные шрифты. Для полного автономного режима удалите `<link>` Google Fonts из `index.html`.

## Публикация на GitHub Pages

Проект готов к публикации из корня репозитория: `index.html`, `styles.css`, `script.js` и `config.js` используют относительные пути. На GitHub Pro можно хранить исходный репозиторий приватным и включить GitHub Pages для ветки `main` и корневой папки. Опубликованный сайт и его статические файлы всё равно будут доступны публично; не добавляйте в проект пароли, токены или другие секреты. На GitHub Free для Pages требуется публичный репозиторий.
